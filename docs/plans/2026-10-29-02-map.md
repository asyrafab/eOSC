# eOSC+ Plan 2: Map — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Members open a meeting map that shows each agenda item's site over current lots, zoning and other reference layers, the applicant's layout plan in place, current imagery, and past OSC decisions nearby, and keeps working when the ArcGIS portal is down.

**Architecture:** iNDECS core capability C13 (GIS) is built here, generically. Reference layers are copied from ArcGIS Enterprise into PostGIS with `ogr2ogr` as dated snapshots, and served to the browser as Mapbox vector tiles (`ST_AsMVT`) from iNDECS itself. Agenda items and past decisions are served as GeoJSON, filtered by `OscAccess::canViewItem`. The browser map uses OpenLayers, vendored under `public/vendor/openlayers` (no build step). Boundaries are drawn at registration with OpenLayers Draw/Modify snapped to lots. Scanned layout plans are placed by four corners computed server-side and drawn client-side with a canvas affine transform.

**Tech Stack:** Laravel (existing), PostgreSQL 18 + PostGIS 3 (`ST_Transform`, `ST_TileEnvelope`, `ST_AsMVT`), GDAL `ogr2ogr` from `C:\Program Files\PostgreSQL\18\bin` (path set by `GIS_OGR2OGR` in `.env`), OpenLayers 10.x (pinned), Esri World Imagery and World Street Map tiles.

**Spec:** `docs/eosc/README.md` (approved v1.1): sections 8.2 (map), 9.3 (boundaries and positioned layout plans), 13 (integration), 14 (legacy), 15 (availability), 16 (reduced first versions). Plan 1 code is the base: branch `feat/eosc-foundation`. Create `feat/eosc-map` from it.

## Review Focus

1. **ArcGIS down, slow or returning an error during a refresh:** the active snapshot stays live, nothing half-imported becomes visible, and the command exits non-zero with a BM message. Test in Task 2.
2. **A user who may not see an item** (another department's proposal, a returned item) gets no boundary, layout image or popup for it through map data, layout images or tiles. Test in Task 3 (map data, layout image route).
3. **A drawn boundary that is self-intersecting, empty, a line, or outside MBSP** is refused with a BM message, and nothing is stored. Test in Task 6.
4. **Legacy records with no XY, a missing image, an image without a world file, or a TIFF** are skipped and listed in the command summary; the import continues and can be rerun without duplicates. Test in Task 4.
5. **Internet lost in the meeting room:** imagery tiles fail and the map shows the notice; lots, zoning, items and layout images still render from iNDECS. Check in Task 5 (config test plus manual browser check with the network blocked for `server.arcgisonline.com`).

**Interfaces:**
- `ArcGisToken::get(): ?string`
  - With `ARCGIS_USERNAME` empty, returns null.
  - Otherwise POSTs to `{portal}/sharing/rest/generateToken` with `client=referer`, `referer=config('app.url')` and `expiration=60`, and caches the token for 50 minutes.
  - On error, throws `RuntimeException('Token ArcGIS tidak dapat dijana.')`.
- `LayerReplicationService::replicate(GisLayer $layer, ?User $actor = null): GisLayerSnapshot`
  1. Creates a snapshot with status `importing`.
  2. Runs `ogr2ogr` through `Symfony\Component\Process\Process` (argument array, never a shell string), with these arguments:
     - `-f PostgreSQL PG:"<connection from config('database.connections.pgsql')>"`
     - `<source>`: for an `http(s)` source, `{source_url}/query?where={where}&outFields=*&outSR=4326&f=json` plus `&token=` when present; for `file://` sources (tests), the file path
     - `-oo FEATURE_SERVER_PAGING=YES`
     - `-nln core.gis_import_{snapshotId}`
     - `-nlt PROMOTE_TO_MULTI`
     - `-lco GEOMETRY_NAME=geom`
     - `-t_srs EPSG:4326`
     - `-overwrite`
     - timeout 1800 s
  3. In one transaction:
     - inserts into `core.gis_features (snapshot_id, geom, geom_web, attributes)`, using `ST_MakeValid(geom)`, `ST_Transform(..., 3857)` and `to_jsonb(row) - 'geom' - 'ogc_fid'`;
     - drops the staging table;
     - refuses a zero-feature result (`Lapisan sumber tidak mengandungi rekod.`);
     - sets the snapshot `ready` with `feature_count`;
     - points `layer.active_snapshot_id` at it;
     - marks the previous ready snapshot `superseded`;
     - writes audit event `gis_layer_replicated`.
  4. On any failure: drops the staging table if present, sets the snapshot `failed` with the token-redacted error, leaves `active_snapshot_id` unchanged, writes audit `gis_layer_replication_failed`, then rethrows.
  5. Deletes features of `superseded` snapshots older than the last two.
- `php artisan gis:replicate {layer?} {--all}`
  - Prints `Lapisan {id}: {n} rekod` per layer.
  - Exits 1 if any layer failed, after attempting the rest.
- `ReplicateLayers` job (queued) is the same as `--all`, with `$actor`.
- `GisLayerSeeder` seeds layers from `config('gis.layers')`. Initial entries:
  - `lots`: `Lot kadaster`, from `Kadaster/KADASTER`
  - `zoning`: `Zon guna tanah`, from `Gunatanah/Gunatanah`

  - `legacy_mjkp`: `Keputusan terdahulu`, from `DEMARCATION/MJKP_eOSC/FeatureServer/1204`, kind `legacy_papers`

  Source URLs are full FeatureServer layer URLs under `https://spgis.mbsp.gov.my/geoportal/rest/services/`. ### Task 4: Legacy MJKP points and layout images

**Files:**

- Create: `tests/Fixtures/gis/legacy/` (a 40×20 px JPG, its `.jgw` with rotation terms, a `.jpg` without `.jgw`, a `.tif` + `.tfw`), `tests/Fixtures/gis/mjkp.esrijson` (4 points, one with a `plan_` file present, one missing XY)

**Interfaces:**
- `AffinePlacement::fromWorldFile(array $w, int $width, int $height): array`
  - `$w` = `[A, D, B, E, C, F]`, the six numbers in world-file line order.
  - Returns the four map-space corners `[[x,y]×4]` (top-left, top-right, bottom-right, bottom-left) of the image's outer pixel edges: `x = A*col + B*row + C - (A+B)/2`, `y = D*col + E*row + F - (D+E)/2`, for `(col,row)` in `(0,0)`, `(width,0)`, `(width,height)`, `(0,height)`.
- `AffinePlacement::fromControlPoints(array $pixel, array $map, int $width, int $height): array`
  - Takes three pixel points `[[col,row]×3]` and three map points `[[x,y]×3]`.
  - Solves the 6-parameter affine.
  - Returns the four corners (same shape as `fromWorldFile`) of a `width`×`height` image.
  - Throws `InvalidArgumentException('Titik kawalan tidak sah.')` when the three points are collinear (|det| < 1e-9).
- `php artisan osc:import-legacy {--points} {--images} {--srid=990001} {--dir=O:\Projects\mjkp\web\plan}`
  - **Points** (`--points`):

  - **Images** (`--images`):

  2. For each, compute the share of the paper's point (from ArcGIS) that falls inside its image's corner polygon.
