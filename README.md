# eOSC+

The OSC meeting room for Majlis Bandaraya Seberang Perai: agenda, map, chairperson's decisions, attendee
mobile view and video call to the PSP or Owner, used during Jawatankuasa OSC meetings.

eOSC+ is built **inside iNDECS** as core capability C10 (ADR-213). This repository holds its project
documents; the code lives in the iNDECS repository.

| Document | Content |
|---|---|
| [docs/eosc-plus-design.md](docs/eosc-plus-design.md) | Approved design (v1.1, 2026-10-29) |
| [docs/plans/](docs/plans/README.md) | Build plans, one per subsystem |
| [docs/runbooks/eosc-agenda.md](docs/runbooks/eosc-agenda.md) | Operating the agenda builder |

These files mirror `docs/eosc/` and `docs/runbooks/eosc-agenda.md` in iNDECS, which are the canonical
copies. Both are updated together.
